1. A Markdown guide consolidating quality community posts, official blogs, research papers, open-source projects, and hands-on engineering practices into an actionable AI Agent learning checklist: [Agent-Learning-Hub](https://github.com/datawhalechina/Agent-Learning-Hub)
2. Anthropic's engineering blog—a must-read is **"Building Effective Agents"**: [Anthropic Engineering](https://www.anthropic.com/engineering)
3. A highly-starred, open-source systematic tutorial on building and implementing agent systems from scratch: [Hello-Agents](https://github.com/datawhalechina/Hello-Agents)
4. Featured post - [Comprehensive Roadmap for AI Application Development](https://www.nowcoder.com/discuss/847995166416703488?sourceSSR=users)
5. Harness-pattern agents: highly recommended to dive directly into the source code of Claude Code and Pi: [Learn Claude Code](https://github.com/shareAI-lab/learn-claude-code); an insightful deep dive into the Pi agent: [pi-coding-agent](https://mariozechner.at/posts/2025-11-30-pi-coding-agent/)
6. The LangChain ecosystem: after understanding the core [Langchain](https://github.com/langchain-ai/langchain) library, try exploring and reproducing [LangGraph](https://github.com/langchain-ai/langgraph) and [DeepAgents](https://github.com/langchain-ai/deepagents); leverage [LangSmith](https://www.langchain.com/langsmith/observability) for trace monitoring, trajectory inspection, and agent evaluation.
7. Agent evaluation: an LLM-as-a-Judge framework tailored for LLMs and AI Agents; currently, [OpenJudge](https://github.com/agentscope-ai/OpenJudge) stands out as a remarkably comprehensive open-source project.
