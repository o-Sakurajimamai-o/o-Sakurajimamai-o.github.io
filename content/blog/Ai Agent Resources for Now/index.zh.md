1. md文件，负责优秀分享、官方博客、论文、开源项目和真实工程经验，整理成一份可以照着执行的 AI Agent 学习 todo list：[Agent-Learning-Hub](https://github.com/datawhalechina/Agent-Learning-Hub)
2. Anthropic 的工程博客，务必精读 **《Building Effective Agents》**：[Anthropic Engineering](https://www.anthropic.com/engineering)
3. 开源的高 Stars 系统性智能体学习教程，从零开始进行的 Agent 系统构建与实战：[Hello-Agents](https://github.com/datawhalechina/Hello-Agents)
4. 优秀博文 - [AI应用开发学习全景路线图](https://www.nowcoder.com/discuss/847995166416703488?sourceSSR=users)
5. Harness 架构下的 Agent，推荐直接去阅读 Claude Code 和 Pi 的源码：[Learn Claude Code](https://github.com/shareAI-lab/learn-claude-code)，关于 pi agent 的优质博文：[pi-coding-agent](https://mariozechner.at/posts/2025-11-30-pi-coding-agent/)
6. LangChain 生态，在了解 [Langchain](https://github.com/langchain-ai/langchain) 的基础包情况下，可以尝试着学习和复现 [LangGraph](https://github.com/langchain-ai/langgraph)、[DeepAgents](https://github.com/langchain-ai/deepagents); 项目使用 [LangSmith](https://www.langchain.com/langsmith/observability) 做轨迹追踪和Agent测评。
7. Agent 测评，大语言模型与 AI Agent 打造的 LLM-as-a-Judge 框架，目前：[OpenJudge](https://github.com/agentscope-ai/OpenJudge) 作为开源项目较为全面。
