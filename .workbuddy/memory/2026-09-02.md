## 给文章代码块加折叠按钮

- 渲染钩子：`layouts/_default/_markup/render-codeblock.html`，所有围栏代码块套一层带语言/行数/复制/折叠按钮的 `.code-box`。
- 折叠逻辑：三级开关从局部到全局，单块 `{fold=false|true|full}` > 文章 front matter `codeFold: false` > `hugo.toml [params.codeFold]`。
- 行数低于 `threshold`（默认 10）自动豁免，强制折叠用 `{fold=true}`。
- 样式：`assets/css/custom.css` 替换原"浮动复制按钮"段，新增 `.code-bar`、`.code-fade`、`.code-more`、`.code-fold` 等规则，折叠按钮在折叠态常驻可见，复制按钮仍 hover 显示。
- JS 合并：`layouts/partials/codefold.html` 同时处理折叠和复制（替代并删除了 `codecopy.html`），由 `baseof.html` 末尾全局引入，所有页面都生效。
- i18n 新增 `expand` / `collapse` / `nLines` / `expandLines`（中英两套）。
- 坑：
  1. Go 模板 `with` 对布尔 `false` 当空值跳过，必须用 `isset + index` 取开关值，否则 `{fold=false}` 永远失效。
  2. Hugo 把 params 键转小写，所以同时认 `codeFold` 和 `codefold`。
  3. `hugo.toml` 已写全所有 `[params.codeFold]` 子键，所以模板里也用 `isset` 防御。
  4. 默认站点的 `public` 目录被占用（报错 Access is denied），用 `-d .hugo-verify` 临时输出目录绕开验证，环境问题与代码无关。
